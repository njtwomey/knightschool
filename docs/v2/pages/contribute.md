# Contribute

How someone outside the project can suggest or add an opening. A short page for the curious, not the standard itself.

## Address

`/contribute`. No hash ([../navigation/url-state.md](../navigation/url-state.md)).

## Reached from

The footer of every page ([page-shell](../components/page-shell.md)), as **Add an opening**.

## Layout

[breadcrumbs](../components/breadcrumbs.md): Add an opening. The heading, one sentence, then three sections:

1. **Suggest one**: a link to a new GitHub issue.
2. **How openings are chosen**: the three tests and breadth first, in plain words, from `CLAUDE.md`.
3. **Write one yourself**: what an opening is made of, with links to
   [making-openings](../making-openings.md) and the `add-content` skill, then a pull request.

## Behaviour

Static. It links to the standard and the procedure in the repo rather than repeating them, so they stay in one place.

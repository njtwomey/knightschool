# Decisions

Everything in the v2 plan that needs the user, in one place, each with the recommended answer and where it is raised.
Stored-format decisions come first, because they are the hardest to undo once learners have data. Questions already
settled (the vocabulary, one set of states, addresses, settings against config, arrows, names, reading games from
Lichess and Chess.com) are not repeated here.
